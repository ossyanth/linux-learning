# Linux Learning - Day 1

## Objectives

- Install Ubuntu using WSL
- Learn basic terminal commands
- Create files and directories
- Understand hidden files

## Commands Learned

### pwd
Print the current working directory.

### ls
List files.

Useful flags:

```bash
ls
ls -la
```

### cd
Change directory.

### mkdir
Create directories.

### touch
Create files.
